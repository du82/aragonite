# Project Title *
## This project name can be changed if a full proposal is requested.

Aragonite - Privacy Search Engine

# Describe your project in 1-3 sentences.

A truly secure search engine with zero client-side JavaScript and complete Tor compatibility, allowing censorship-resistant access to information through distributed mirrors. The system can operate fully airgapped, online, or offline, with a transparent infrastructure that users can verify. Its minimal attack surface and flexible deployment options make it uniquely suited for privacy-sensitive environments, conflict zones, and regions experiencing internet restrictions.

# What problem will your project address?
## Describe the problem that exists. What change is needed? How will your project contribute to solving this problem?

Current search engines force users to choose between functionality and privacy. 'Private' search engines typically rely heavily on JavaScript, creating numerous security vulnerabilities and making them barely usable over Tor. Meanwhile, users in restricted environments need reliable access to information without exposing themselves to surveillance or tracking. This project solves both problems by providing a fully-functional search engine with virtually no attack surface - it uses zero client-side JavaScript, works seamlessly over Tor, can be easily mirrored to bypass censorship, and can even operate offline or air-gapped. Unlike existing solutions that offer privacy through marketing promises, our system provides privacy through fundamental technical design.

# Are there similar projects that exist already? How is your project different or complementary to those projects?
## What gaps does your project address? Does your project build on these projects? If so, how? Is there opportunity for collaboration? Provide web links if available.

While users can access DuckDuckGo, Mojeek, or SearXNG through Tor, this creates fundamental privacy and usability challenges. These services maintain complex server infrastructures that could potentially log or be compromised, requiring users to trust their privacy promises rather than verifiable technical guarantees. They are also highly centralized - if their domains are blocked or servers compromised, users lose access entirely. Even Tor access can be disrupted by ISP-level blocking. Our distributed mirror system provides genuine resilience - even if Tor is blocked and primary domains are censored, users can still access mirrors through various paths. Unlike SearXNG instances which can be poorly maintained or unstable, our simplified architecture enables mirrors to be reliably operated with minimal overhead. Users can verify exactly what code is running through neofetch, rather than trusting privacy policies or hoping volunteer instances are properly configured. Simply accessing existing search engines through Tor provides a false sense of security, while our system provides verifiable privacy guarantees through its fundamental design and demonstrated reliability through its distributed architecture.

# Who would benefit from this project?
## Tell us about the people who will use this project? How is it relevant to them?

This project primarily benefits users who need reliable, private access to information in challenging environments: journalists and researchers working on sensitive topics, individuals in regions with heavy surveillance or censorship, human rights organizations needing secure search capabilities, and privacy-conscious users who want verifiable rather than promised security. The system's ability to operate offline or through mirrors makes it particularly valuable during internet shutdowns or in conflict zones. Small organizations can easily host verified mirrors, enabling community-driven distribution of access. Privacy-focused libraries and educational institutions can deploy local instances without worrying about complex security configurations. The project's minimal and verifiable architecture also benefits the broader privacy tool ecosystem by demonstrating how to build genuinely secure services without relying on privacy theater. Our existing community of several hundred users has already demonstrated the real-world value for these use cases.
